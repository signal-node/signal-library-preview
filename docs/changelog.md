# 変更履歴

## 0.1.0（限定サポートの初版）

本体はMIT。登録、Mistral OCR、失敗/中断からの回復、本文の7要件整形、校正版/範囲照合/採用管理、既存MDを含むHTML/PDF生成と旧版判定・別ID再生成を提供します。

macOS Codexの限定対話、人工資料のDropbox同期/Web再取得、CLIの3 OS CIを区別して記録しました。Windows実端末、Claudeの実対話、実キー設定から新規実OCRまでのAgentによる一巡は未確認で、未確認の組合せは実験的対応です。[確認環境と未確認事項](known-limitations.md)を参照してください。

0.1.0.dev1からは、受入結果/未確認事項/サポート範囲の案内とversion・配布検査を更新。書籍schema、CLI処理、旧版の照合や出力を変更していません。

## 0.1.0.dev1（公開済み開発プレビュー）

配布物内の互換テストに必要な移管用2ファイルを追加し、候補内の全回帰を配布検査へ追加。公開main/tagの通常/SDK/配布CI成功と匿名取得/Release ZIP一致を確認しました。

## 0.1.0.dev0（公開済み開発プレビュー）

初回プレビュー。互換テスト依存2ファイルの配布漏れにより公開CIが失敗したためdev1で修正。旧commit/tag/ZIPを保持しています。
