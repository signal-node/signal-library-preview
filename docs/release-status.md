# 配布候補の状態

0.1.0.dev0。本体はMITを採用（2026-10-16）。安定版公開は未実施。配布候補は閲覧・監査用であり、初版の全受入が完了したと説明しない。

## 検証の証拠

I-01〜09で初期化・登録・OCR回復・整形/照合/採用・HTML/PDF・旧版判定/再生成を実装。通常/SDK模擬HTTP/実エンジンは3 OS CIで検証した。実APIは利用者が許可した自作PNG1枚だけで送信/回収/比較に成功し、別途許可後に試験用リモート3件を削除した。実書籍は試験資料として同梱/送信していない。

HTMLは利用者が人工資料のオフライン・コピー先表示を確認。PDFは人工資料の全ページ画像、埋込み、コピー単体のネットワーク拒否描画、代表経路の検索/選択/目次操作を確認した。これらの結果は確認対象のhashへ固定しており、新しく作る出力へ合格を継承しない。

I-10の入口/診断に加え、コピー復元後のOCR再接続を実装。旧manifest/operationを保持し、再送なしで同じrun/jobから続ける。追加9件を含む標準/SDK165件と旧統合8件がローカルで成功。通常/SDK/配布build/install検証はmacOS/Windows/Linuxですべて成功。実Agentの新規対話やクラウド同期の代わりにはしない。[未完了の受入](acceptance/agent-onboarding.md)を参照。

## 配布対象外の開発記録

開発正本には移管経緯・個人運用・試験の詳細記録を保持するが、この配布候補には含めない。共有文書の開発記録へのリンクはこの状態ページへ対応させる。配布候補manifestに、対象ファイルとhash、生成した入口/リンク変換を記録する。

## 開発プレビューの配布方針（承認済み）

2026-10-16、利用者は未確認事項を明示した開発プレビューの配布準備を先行する方針を承認した。0.1.0.dev0として、許可リストのコード・共通文書・空の雛形・人工資料だけを配布対象にする。安定版/I-10完了とは扱わず、既存の初版完了条件を維持する。

実OCR/校正の新規Agent対話、Claude Code、Windows実端末GUI、Dropboxのクラウド同期/再取得は未確認として残す。利用者にはClaude契約やWindows機の確保を要求しない。開発プレビューを準備する承認は、公開先の作成・visibility変更・公開push・Release作成の承認を含まない。具体的な公開対象を用意して最終判断へ進む。

判断理由: CLIとエンジンの3 OS検証、macOS Codexのキーなし導線、限定した自作PNGの実API、人工HTML/PDFの既存表示証拠があり、閲覧・試用向けの候補は用意できている。一方、これらを両Agent/実Windows/クラウド同期の成功証拠に読み替えることはできない。

反証レビュー: 「契約がないならClaude対応を削除して初版完了にできる」は既存要件の変更なので不採用。「Windows CI成功ならGUIも受入済み」は証拠の範囲を超えるので不採用。「ローカルコピーが通るのでDropboxも確認済み」は同期競合・再取得の証拠がないため不採用。プレビューの提案は未確認事項の解消ではなく、配布時の説明と判断を分けるもの。これは同一担当による反証検討であり、新しい独立レビューを実施したという意味ではない。
