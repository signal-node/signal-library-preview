# 初版: MarkdownからのPDF・HTML

作成日: 2026-10-05（JST）
状態: 初版の機能要件。2026-10-06にI-01でエンジンを選定した。HTML生成・台帳・表示確認記録はI-08で実装し、利用者のコピー先・オフライン表示確認を完了。[HTMLの契約](html-export.md)。PDF生成・共通stale判定と新ID再生成はI-09で実装し、人工資料のページ画像を確認。[PDFと出力管理](pdf-export.md)。Gemini TTSは[次期版の検討草案](../release-status.md)へ分離した。

## 位置付け

書籍のMarkdownを、紙面で読むPDFとブラウザで読むHTMLへ変換する。実装計画の段階6で実装する。初版に音声機能やGemini認証を含めない。

入力は採用中の校正版、明示的に選んだ未校正本文、または利用者が持つ既存Markdown。既存Markdownは書籍ID・ファイルhash・由来・確認状態を登録して扱い、OCR由来でない文書にrun_idや原画像対応を捏造しない。PDF/HTMLはローカルで生成し、APIキーがなくても使える。

## 共通の出力管理

- 原Markdownを変更せず、入力版とhashを固定して派生物を生成する。
- `LIBRARY_ROOT`内の書籍配下へ保存。配置案は`exports/pdf/<export_id>/`、`exports/html/<export_id>/`。端末パスをコードに固定しない。
- 記録する項目: book_id、元revision/runまたは登録MDの識別子、対象範囲、本文・参照画像のhash、変換設定、テンプレート・エンジンversion、出力相対パス・hash、作成日時、検証状態。
- 既存exports.csvとの接続を設計し、必要な詳細はexport manifestへ分ける。既存形式への追加・移行は互換性を検討して行う。
- 原文・画像・設定の変更で影響する派生物をstaleとして識別する。古い出力は保持し、新しいexportを作る。
- PDF/HTMLを作成することは、Web公開や他者への送信を意味しない。第三者公開機能は今回追加しない。

## 段階6: PDF・HTML

共通のPandoc 3.12 JSON ASTから、HTML5＋MathMLとTypst 0.15.1 PDFへ出力する。日本語fontはNoto Sans CJK JP Regular Sans2.004を固定版・hashで取得し、HTMLはローカルfont/OFLライセンスを含める。PDFはA4とfontを明示し、長い表のページ分割を有効にする。選定・配布条件と未対応範囲は[I-01判断記録](../release-status.md)を参照。製品の導入・安全な入力処理・export管理はI-08/I-09で実装する。

### PDF

- 書名・使用版・対象章・校正状態、見出し、目次、ページ番号、図表、脚注、数式を保持する。
- 用紙、余白、文字サイズの初期設定を用意し、長い表・数式・画像のページ跨ぎと欠けを検査する。
- 出力PDFのページ番号と原著の紙面番号を区別する。再組版後のページ番号を原典位置として扱わない。
- 日本語フォントの描画・埋込み条件、テキスト検索と選択を確認する。

### HTML

- オフラインで開けるHTMLとローカル資材の束を基本とし、相対参照・目次・章内リンク・可変幅の表示を用意する。
- 書名、見出し構造、文書言語、図の既存説明等を保持する。数式・図を勝手に解説へ置き換えない。
- 元MDの任意HTML/script・危険なURLを無条件に実行しない。許可したレンダラー資材と本文を区別し、外部CDNや任意URLへの自動アクセスに依存しない。
- 参照画像は許可したasset root内の必要ファイルだけ読む。範囲外参照、symlink逸脱、欠落は検出する。

### 検証

日本語、インライン・独立数式、長い表、図、脚注、深い見出し、空白・日本語のファイル名を含む人工MDで検証する。PDFはページを画像化して欠け・重なりを確認、HTMLは実ブラウザで目次・数式・画像・狭い画面を確認する。オフラインで表示でき、別フォルダへコピーしても資材参照が解決することを受入条件にする。変換成功だけで表示確認済みとはしない。
