# 初版の受入条件と未確認事項の扱い

2026-10-17（JST）。状態: 承認済み。

利用者は[比較案](../release-status.md)のBに対し、「未確認事項を明記して初版準備を進めてください」と指示した。macOS/Windows、Codex/Claude Codeは実装対象に維持する。

初版の判定では、macOS Codexの確認済み対話と、共通CLI・許可した少量実API・人工出力の表示・人工資料の保存/再取得の個別証拠を組み合わせて評価する。全経路を実Agentで一巡したとは記載しない。Claudeの実対話/切替、Windows実端末での導入/対話/操作、Codexの実キー設定から新規実OCRまでの一巡と実job回復対話は、初版の公開を止める条件から外す。これらを[未確認事項](../known-limitations.md)として追跡し、未実施を合格に変換しない。

原本/旧版保持、7要件、秘密/パスの境界、送信対象ごとの許可、版を固定した照合、MIT/外部依存の条件、個人情報と実書籍の配布除外は維持する。README・設定・サポート・Release案から確認環境と未確認事項に到達できるようにする。

I-10は[変更後の条件](../acceptance/release-0.1.0.md)を検査して判定する。初版候補のversionは0.1.0とするが、versionの設定だけで公開済みとは扱わない。具体的なcommit/ZIP/検証結果/公開操作を提示し、公開の最終承認を得る。元の開発repoの公開、新しいAIセッション、実API送信、既存クラウド資料の削除は今回の範囲外。Gemini TTSは次期版。

個別試験の組合せでは導入全体の不具合を見逃す可能性が残るため、実端末対話を延期するリスクを制限として明記する。旧条件と比較案は履歴として残し、今後の再検証は未確認事項のIDで管理する。
