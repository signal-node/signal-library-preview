# 0.1.0 初版候補の受入判定

限定サポートの初版を準備する受入条件は[承認済みの決定](../decisions/initial-release-acceptance.md)によります。候補は公開承認前です。個々の証拠を全OS・全Agentの一巡成功へ読み替えません。

| 条件 | 証拠・判定 |
| --- | --- |
| 指定した保存先でのキーなし初期化/登録 | 共通CLIの境界/再実行/新規プロセステスト、macOS Codexの独立対話で確認 |
| Mistral正常系と中断/部分失敗/結果不明の回復 | I-05の許可した人工1ページの実送信/回収/原典比較と、I-06の模擬HTTP/回復/再送抑止テスト。実job回復のAgent対話はR-03として延期 |
| 原本・旧版・ID/hashの保持 | 登録/回復/読書版/出力テスト、別root rebind、独立対話とDropbox再取得で確認 |
| 本文整形の7要件と校正/照合/採用の区別 | 人工紙面比較/整形テスト、Codex独立2セッションの範囲照合と新版への照合非継承を確認。全文の照合済みとはしない |
| 既存MDを含むHTML/PDF、旧版判定と別ID再生成 | 実エンジンの3 OS CI、人工ページ/埋込みと利用者のHTMLコピー先/オフライン操作確認。新出力には表示確認を継承しない |
| 資料内指示、秘密、パス、任意scriptの境界 | パス/symlink/HTML/人工秘密テスト。Codexの人工書誌1例で不正指示を実際に読んで実行せず、キー案内/計画で停止 |
| 保存・復元 | 人工1冊のDropbox単一端末同期/Web ZIP再取得、36ファイル/20ディレクトリと全hash一致、別root再接続とID/原本/旧版保持 |
| 対応環境の説明 | Windows/Claudeを対象に維持。実端末/実対話未確認は実験的対応とし、R-01〜04を追跡 |
| MIT・外部依存と配布境界 | LICENSE/依存通知/許可リスト、資料/秘密/元履歴の除外。候補ごとの混入検査・隔離build/install/CIを公開前に固定対象で検証する |
| Gemini TTS | 初版にキー/SDK/音声機能を要求しない。次期版 |

I-10の確認済み機能と承認済み延期事項の整理は完了。これは旧条件の全実施ではなく、変更後条件による限定した受入判定です。R-01〜03を実施済みに変換せず、[未確認事項一覧](../known-limitations.md)に残します。公開する候補そのもののI-11検証と最終承認は別です。

## レビューで確認した反証

- CI成功だけでWindows実端末/Claudeの受入済みとはしない。延期の承認と未確認の表示で扱う。
- 原典照合、整形、表示、採用、保存を分ける。部分照合や同一本文の別版へ合格を拡張しない。
- Agentの成功報告だけでは判定しない。実コマンド・台帳・全ファイルhash・保存履歴と対応するCLI検証を確認する。
- 複数の個別証拠を組み合わせることの導入リスクは残る。R-03/04で追跡し、対応範囲の説明から隠さない。
- 未確認事項の延期は製品の安全境界を緩和する許可ではない。実送信は引き続き対象別の利用者許可が必要。

詳細な対話と履歴は[導入受入記録](agent-onboarding.md)。この判定は同一担当の反証検討と証拠照合によるもので、別担当の新規独立レビューを意味しません。
