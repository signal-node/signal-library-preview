# 書籍管理の手順

保存先と利用者の運用方針を確認し、[共通作業手順](../agent-workflow.md)に従う。所有者のDropboxパス、アカウント、読書記録を第三者へ適用しない。具体的なCLI契約は共通手順から必要なものを読む。

登録時は撮影順・欠落・画質を目視確認する。OCR原文を保持し、ヘッダ/フッタ除去、見出し/段落の統一、図は画像、表はMD表、日本語の読点「、」（数式は除外）、文中折返し結合の7要件を整形計画で実現する。修正は新revisionに残す。

原典照合、整形、採用、表示確認、クラウド同期は別の状態。引用・カード化する範囲は使用版と原典位置を確認する。PDFの再組版ページ番号を原著の紙面番号と混同しない。

保存先がDropboxの場合も、原本・本文・台帳のローカル検証だけでクラウド保存済みとしない。同期・再取得の証拠を確認する。外付け媒体や別保存サービスを開始条件に追加する指示ではない。
